# Sistema de Produtos em Java

Projeto desenvolvido para prática de Programação Orientada a Objetos em Java durante o curso de Análise e Desenvolvimento de Sistemas.

## 📚 Descrição

Este sistema simula o cadastro de produtos utilizando conceitos de Programação Orientada a Objetos (POO).  
O programa permite cadastrar produtos, armazenar suas informações e exibir os dados no console.

O projeto foi desenvolvido utilizando a linguagem Java e executado na IDE Eclipse.

## ⚙️ Funcionalidades

- Cadastrar produtos
- Informar nome e preço do produto
- Exibir dados dos produtos cadastrados
- Contar a quantidade total de produtos cadastrados

## 🛠 Tecnologias utilizadas

- Java
- Eclipse IDE

## ▶️ Como executar o projeto

1. Abrir o projeto no Eclipse
2. Executar a classe `Principal.java`
3. O sistema exibirá os dados dos produtos no console

Exemplo de saída no console:


Nome do produto: Notebook
Preço: 3500.0

Nome do produto: Mouse
Preço: 80.0

Nome do produto: Teclado
Preço: 150.0

Quantidade total de produtos cadastrados: 3
